## Architecture Decisions
- Monorepo com npm workspaces: apps/hub, apps/backbone, database
- Frontend: React 19 + Vite + Tailwind 4 + shadcn/ui (tema Mira: Gray + Fuchsia)
- Backend: Hono + Node.js (leve, Web Standards)
- Database: PostgreSQL 16 com migrations SQL idempotentes
- Auth: JWT (15min access, 7d refresh) + bcrypt (cost 12) + HTTP-only cookies
- Real-time: SSE (Server-Sent Events) com chokidar file watching + debounce 500ms
- Agent Kai: LangGraph.js com graph classify→reason→act→respond, 12 tools
- LLM: OpenRouter (Gemini Flash para classify/reason, Claude Haiku para respond)
- PWA: Workbox + Service Worker + Web Push API + VAPID
- Mobile-first: bottom nav mobile, sidebar desktop, breakpoint md (768px)
- Validacao: Zod em todo input (frontend + backend)
- Projetos/features/workspaces vivem no filesystem (JSON), nao no banco
- Banco armazena: users, auth, conversas Kai, notificacoes, settings, onboarding
