## Architecture Decisions
- ES Modules (.mjs) em toda a stack — substitui bash scripts
- API deterministica em runs/.meta/api/ — CLI + SDK importavel
- project.json como formato unico de projeto (substitui run configs atuais)
- Dois formatos de filesystem: flat (runs/{slug}.json) e structured (runs/{slug}/project.json)
- agent-harness.mjs substitui agent-harness.sh como loop principal
- Slash commands viram thin wrappers que delegam para API MJS
- Validacao via ajv contra JSON Schemas
- Unica dependencia externa: ajv — resto usa node: built-ins
- Cross-platform: funciona em Windows sem Git Bash/MSYS2
- Workspace autonomo apos inicializacao (independente do swarm-factory)
- Loop unificado: max_features=1 substitui conceito de "sessao manual"
- Gutter detection: max_retries falhas -> rotacao de contexto -> skip
- Webhooks fire-and-forget com fetch nativo
